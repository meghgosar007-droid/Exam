# Assignment 8 - Direct mapped vs 2-way set associative cache
1 GB main memory, 64 KB cache, 4 B blocks.
Direct mapped: 14-bit tag | 14-bit index | 2-bit offset. 2-way: 15-bit tag | 13-bit set | 2-bit offset.
`cache_mapping.ipynb` simulates both on the same address trace (both: 3 hits / 9 misses = 25%).
